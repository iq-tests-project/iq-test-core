# iq-test-core

Минимальный шуточный одностраничный сайт с тестом на IQ.

## Как запустить

Открой `index.html` в браузере напрямую или через любой локальный статический сервер.

## Что внутри

- лендинг с громкими обещаниями;
- 5 вопросов без регистрации и без сохранения ответов;
- финальная плашка с заблюренным результатом.
